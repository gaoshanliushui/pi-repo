# 工具参考

`pi-subagents` 给 Pi 注册两个工具（`src/extension/index.ts:459-531`）：

| 名称 | 何时用 |
|------|--------|
| `subagent` | 主入口：执行一个/多个 agent，或查询/管理 agent/chain/运行状态 |
| `wait` | 阻塞当前 turn，等后台子代理完成（用于 `pi -p` 等没有"下一个 turn"的场景） |

工具参数 schema 见 `src/extension/schemas.ts`。

---

## subagent

### 三种执行模式（互斥）

| 模式 | 触发字段 | 含义 |
|------|----------|------|
| **SINGLE** | `agent` + `task?` | 一个 agent 跑一个任务；省略 `task` 表示 self-contained agent |
| **PARALLEL** | `tasks: [{agent, task?, count?, ...}]` | 并发跑多个任务；可配 `concurrency`、`worktree` |
| **CHAIN** | `chain: [{...}, {...}]` | 顺序步骤；每步用 `{previous}` 接上一步；可嵌入 `parallel` / `expand+collect` |

### TaskItem（parallel）

```json
{
  "agent": "reviewer",
  "task": "Review for correctness",
  "count": 1,
  "cwd": ".",
  "output": "review.md",
  "outputMode": "inline",
  "reads": ["src/a.ts"],
  "progress": false,
  "model": "anthropic/claude-sonnet-4",
  "skill": ["code-review"],
  "toolBudget": { "soft": 30, "hard": 50, "block": ["edit","write"] },
  "acceptance": "reviewed"
}
```

- `count > 1` 时同一个任务重复跑 N 次（每次独立 runId，输出独立）
- `output` 是文件名或 `false`（禁用文件输出），相对路径相对 `cwd`
- `outputMode`: `"inline"`（同时返回内联文本）或 `"file-only"`（只返回路径引用）
- `reads` 是任务开始前要读的文件列表；可 `false` 禁用
- `progress: true` 让 agent 维护 `<chain_dir>/progress.md`
- `toolBudget.block` 数组里写工具名，超出 hard 后这些工具被屏蔽；`"*"` 表示全部
- `acceptance` 见下面的"验收"

### ChainItem（chain 步骤）

可以是顺序步骤、并行段、或动态 fan-out：

```jsonc
{
  "agent": "planner",
  "task": "Plan based on:\n{previous}",          // 模板变量
  "phase": "plan",                                  // 分组标签
  "label": "Make a plan",                            // 用户向标签
  "as": "plan",                                      // 暴露为 {outputs.plan}
  "outputSchema": { "type": "object", ... },         // 结构化输出校验
  "output": "plan.json",
  "reads": ["context.md"],
  "skill": false,                                    // false 禁用 skills
  "model": "anthropic/claude-opus-4",
  "toolBudget": { "hard": 80, "block": "*" },
  "acceptance": { "level": "verified", "verify": [{"id":"typecheck","command":"tsc --noEmit"}] }
}
```

并行段嵌入：

```jsonc
{
  "parallel": [
    { "agent": "reviewer", "task": "Check correctness" },
    { "agent": "reviewer", "task": "Check tests" }
  ],
  "concurrency": 4,
  "failFast": false,
  "worktree": true
}
```

动态 fan-out：

```jsonc
{
  "expand": {
    "from": { "output": "items", "path": "/items" },   // 从前一步 outputs.items 抽出数组
    "item": "item",                                    // 模板里的变量名
    "key": "/id",                                      // 稳定 child id 用的 JSON Pointer
    "maxItems": 20,                                    // 必须设上限
    "onEmpty": "skip"
  },
  "parallel": {
    "agent": "scout",
    "task": "Investigate {item.title}",
    "phase": "fanout"
  },
  "collect": { "as": "investigations" }
}
```

### 全局字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `agent` | string | SINGLE 模式 agent 名；或 action 模式下的目标 agent |
| `task` | string | SINGLE 任务文本；支持 `{task}` `{previous}` `{chain_dir}` `{outputs.<name>}` |
| `action` | string | 进入管理模式，见下表 |
| `id` / `runId` | string | action 模式下的运行 id 或前缀 |
| `dir` | string | action 模式下的 async dir |
| `index` | integer | 多 child 运行时选择具体 child（0 基） |
| `view` | `"fleet" \| "transcript"` | `action: "status"` 的视图 |
| `lines` | integer (1-500) | transcript 视图最大行数（默认 80） |
| `message` | string | `resume` / `steer` 的消息 |
| `scope` | `"session" \| "user" \| "project"` | `watchdog.configure` 的持久化范围 |
| `target` | `"main" \| "children" \| "child"` | watchdog 配置目标 |
| `thinking` | string \| false | watchdog thinking 等级 |
| `schedule` | string | `+10m` 或 ISO timestamp（带时区） |
| `scheduleName` | string | `action: "schedule"` 的显示名 |
| `chainName` | string | chain 管理时用 |
| `config` | object \| string | `create` / `update` 的 agent/chain 定义（JSON 字符串也接受） |
| `tasks` | array | PARALLEL 模式任务数组 |
| `concurrency` | integer | top-level PARALLEL 并发上限（默认 4 或 `config.parallel.concurrency`） |
| `worktree` | boolean | 是否给并行任务建独立 git worktree |
| `chain` | array | CHAIN 模式步骤数组 |
| `context` | `"fresh" \| "fork"` | 显式覆盖每个 child 的上下文继承；省略时各 agent 用各自 `defaultContext`，没设就是 fresh |
| `chainDir` | string | 持久化的 chain artifact 目录；缺省用用户级 temp |
| `async` | boolean | 后台跑（默认 false，可由 `asyncByDefault: true` 改） |
| `timeoutMs` / `maxRuntimeMs` | integer | 整 run 的运行上限；前台/异步都生效 |
| `turnBudget` | object | `{ maxTurns, graceTurns? }` |
| `toolBudget` | object | `{ soft?, hard, block? }` |
| `agentScope` | `"user" \| "project" \| "both"` | agent 发现范围（默认 both；project 优先） |
| `cwd` | string | 工作目录 |
| `artifacts` | boolean | 是否写 debug artifacts（默认 true） |
| `includeProgress` | boolean | 结果是否包含完整 progress（默认 false） |
| `share` | boolean | 是否上传会话到 GitHub Gist |
| `sessionDir` | string | 会话日志目录 |
| `clarify` | boolean | true → 走 TUI 预览/编辑再执行；保留 foreground |
| `control` | object | 控制子代理注意力检测（详见 [configuration.md](配置参考.md#control-子代理注意力)） |
| `output` | string \| false | SINGLE 输出文件路径或 false 禁用 |
| `outputMode` | `"inline" \| "file-only"` | SINGLE 输出返回方式 |
| `skill` | string \| string[] \| false | 启用 skill；false 禁用 |
| `model` | string | 覆盖模型（`provider/id` 或 `provider/id:thinking`） |
| `acceptance` | string \| object \| false | 验收策略 |

### 管理 / 控制 action 表

| action | 必填 | 行为 |
|--------|------|------|
| `list` | — | 列出可执行的 agent / chain |
| `get` | `agent` 或 `chainName` | 返回详细定义 |
| `models` | `agent?` | 展示 builtin agent 当前的运行时 model 映射 |
| `create` | `config` | 新建 agent 或 chain（`config.steps` 数组存在时视为 chain） |
| `update` | `agent` 或 `chainName` + `config` | 合并更新（merge，不替换整文件） |
| `delete` | `agent` 或 `chainName` | 删除 |
| `eject` | `agent`, `agentScope?` | 把 builtin/package agent 拷贝到 user/project 作为可编辑副本 |
| `disable` | `agent`, `agentScope?` | 用 settings 覆盖把 agent 从发现里藏起来 |
| `enable` | `agent`, `agentScope?` | 解除 disable |
| `reset` | `agent`, `agentScope?` | 删除 user/project 中的覆盖，恢复 builtin 默认 |
| `doctor` | — | 输出诊断报告（运行时路径、发现、intercom、permission system） |
| `watchdog.status` | — | 看 watchdog 当前配置和最近一次 review |
| `watchdog.check` | — | 手动触发一次 watchdog 检查 |
| `watchdog.recommend-model` | — | 推荐互补的强模型 |
| `watchdog.configure` | 视字段而定 | 设置 watchdog model / thinking / scope / target / agent |
| `status` | `id?` 或 `view: "fleet"` | 查看异步运行状态、fleet、transcript |
| `interrupt` | `id?` | 软中断当前 child turn，run 进入 `paused` |
| `stop` | `id` | 停止当前 session 的 top-level 异步 run |
| `resume` | `id` + `message` | 对 paused / 已完成 child 投递 follow-up |
| `steer` | `id` + `message` | live async child 上的非终止性指导 |
| `append-step` | `id` + `chain` | 在 chain 尾部追加一个步骤 |
| `schedule` | `schedule` + (agent\|tasks\|chain) | 延迟启动子代理（必须先开启 `scheduledRuns.enabled`） |
| `schedule-list` | — | 列出本 session 计划好的 run |
| `schedule-status` | `id` | 看一个计划的详情 |
| `schedule-cancel` | `id` | 撤销计划 |

> ID 解析：传 `id` 时既支持完整 runId，也支持前缀；用 `index` 选 multi-child run 里的具体 child。

### 工具描述模式

`toolDescriptionMode` 控制注入给模型的工具描述：

- `"full"`（默认）：完整说明 + 安全提示
- `"compact"`：精简版，节省 token
- `"custom"`：从 `subagent-tool-description.md`（project 优先，再 user）读取自定义描述（≤ 50 KB）

可写 `~/.pi/agent/extensions/subagent/subagent-tool-description.md` 或 `<project>/.pi/subagent-tool-description.md`。

## wait

阻塞当前 turn 直到后台子代理运行结束（或需要 attention）。

### 参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 等指定 run（id 或前缀）。省略则等本 session 全部活跃 run |
| `all` | boolean | true 时阻塞直到**所有**活跃 run 结束；默认 false（第一个结束就返回，方便滚动替换） |
| `timeoutMs` | integer | 超时（毫秒）。超时后 wait 返回但 run 继续跑。默认 1800000（30 分钟） |

### 行为细节

- 默认 `{}`：返回第一个完成的 run（适合 fleet manager：launch N → wait → 补一个 → 再 wait）
- `{ all: true }`：等到 session 内全部活跃 run 都结束
- `{ id: "abc" }`：只等这一个
- 子代理完成 / 失败 / 暂停 / 需要 attention 时都会结束 wait
- 等待机制：优先通过 Pi 事件总线即时唤醒；轮询作为 fallback 校验
- `PI_SUBAGENT_WAIT_TOOL_ENABLED` 环境变量或 `config.waitTool.enabled` 可禁用 wait

### 何时用

- 非交互场景（`pi -p ...`），整个任务只有一个 turn，结束 turn 就丢了通知
- skill 必须跑完才能进入下一步
- 编排脚本里需要同步等后台结果

**不要**用 wait 替代 sleep/poll 来"等到任务完成"——除非本 turn 必须阻塞，否则让父模型继续工作，由完成通知自然唤醒。

## action 速查对照

| 想做的事 | action |
|----------|--------|
| 看现有 agent | `list` |
| 看一个 agent 的完整定义 | `get` |
| 复制 builtin 到自己改 | `eject` |
| 临时禁用某个 agent | `disable` / `enable` |
| 还原 builtin 默认 | `reset` |
| 看当前 session 跑着的子代理 | `status` (`view: "fleet"`) |
| 看单个 run 的子代理 transcript | `status` (`view: "transcript"`, `id`, `lines`) |
| 软中断当前 child | `interrupt` |
| 停止一个异步 run | `stop` (`id`) |
| 给 paused / 完成的子代理接着聊 | `resume` (`id`, `message`) |
| 在 live 子代理里排队非终止指导 | `steer` (`id`, `message`) |
| 给 running chain 追加一步 | `append-step` (`id`, `chain`) |
| 配置 watchdog | `watchdog.configure` (`scope`, `target`, `model`, `thinking`) |
| 检查环境/诊断 | `doctor` |
